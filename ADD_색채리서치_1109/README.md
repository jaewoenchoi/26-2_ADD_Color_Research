# 송정동 거리 색채 분석

Windows 64비트에서 ZIP의 압축을 모두 푼 뒤 **색채연구.exe**를 더블클릭하세요. 브라우저가 열립니다. 분석에 필요한 Python, CPU용 PyTorch와 분할 모델이 함께 들어 있습니다. 거리뷰 수집은 Chrome 또는 Edge에서 사용하세요.

**기존 자료 옮기기** — 수정판은 새 폴더에 압축을 푸세요. 이전 폴더에서 기존 작업을 가져오려면 'captures', 'runs', 'analysis_jobs'를 새 폴더에 복사한 뒤, 새 폴더의 색채연구.exe를 열고 **기존 자료 열기 → 이전 분석 결과**를 선택하세요.

**새 작업 시작**을 누르면 현재 선택을 비우고 거리뷰 수집으로 돌아갑니다. 저장한 사진과 분석은 **기존 자료 열기**에서 다시 열 수 있습니다.

작업 표시줄의 알림 영역에서 앱 아이콘을 우클릭하면 브라우저를 다시 열거나 프로그램을 종료할 수 있습니다. 기존 프로그램이 실행 중이라면 작업을 마치고 그 실행 창을 닫아 주세요.

1. **거리뷰 수집** — 첫 화면의 지도 옆에 네이버 Maps Key ID를 넣습니다. 시작점과 끝점을 찍고, 길이 꺾이는 곳에는 중간점을 추가하세요. 사진 수집이 끝나면 **저장한 사진 분석으로**를 누릅니다. 10m는 요청 간격이며 실제 촬영점은 거리뷰에서 반환한 좌표입니다.
2. **사진 분석** — 방금 수집한 사진이 이어서 열립니다. **사진 분석 시작**을 누르면 서연님의 `baseline.pt`가 사진마다 클래스 ID 지도, 흑백 마스크 14장, 투명 배경 클립 14장을 만듭니다. 사진을 넘기며 분할 결과와 원본을 확인하세요. 기존 ZIP이나 이전 결과는 상단의 **기존 자료 열기**에서 고릅니다.
3. **도로 색채** — 1단계에서 정한 조사 구간의 분석 사진이 한 화면에 표시됩니다. 지도에서 촬영 번호나 아래 사진을 선택하세요. 오른쪽에서 사진의 색 분포를 확인할 수 있습니다. 색상 견본이나 사진 속 요소를 고르면 해당 픽셀이 강조되고, **선택만 보기**를 누르면 그 부분만 남습니다. 아래 구간 통합 팔레트는 조사 구간의 분석 사진을 모두 합산합니다. 기본값은 미분류 픽셀도 포함하는 전체 장면입니다. 배경 지도에는 인터넷 연결이 필요합니다.
4. **입면 색채** — 2단계의 분할 마스크로 사진을 가로 방향으로 네 구역으로 나눠 벽, 창문, 출입문, 지붕 색을 따로 계산합니다. 가운데를 비우고 양쪽에 입면 두 채씩을 배치합니다. 지붕 윤곽과 창·문의 배치는 네 채가 서로 다릅니다. 대표색을 최대 4개로 묶어 개념 입면에 넣고, 요소별 실제 색 비율은 아래 팔레트에서 확인합니다. 그림의 위치와 크기는 도식이며, 측정한 건물 치수나 개별 건물 식별 결과가 아닙니다. 사진마다 PNG로 저장할 수 있습니다.
   - 상단 **04 입면 색채**에는 현재 작업에서 분석한 사진이 표시됩니다. 이전 작업을 보려면 **이전 입면·모핑 열기**에서 분석 결과를 선택하세요.
   - **전체 보기**에서 촬영 순서 전체를 한 줄로 겹친 레이어나 펼친 배열로 볼 수 있습니다. 입면 레이어의 빈 부분은 투명해서 뒤의 입면도 보입니다. 레이어 선택 막대로 원하는 장면을 앞에 띄울 수 있습니다. 입면과 원본 사진을 전환하고, 카드를 눌러 개별 결과를 엽니다.
   - **모핑**은 분석된 입면의 색, 띠 비율, 요소 크기를 촬영 순서대로 이어 보여 줍니다. 재생 위치를 조절하거나 Chrome·Edge에서 WebM 동영상으로 저장할 수 있습니다.

새 거리뷰를 수집하려면 네이버 Maps의 Web Dynamic Map용 Key ID와 인터넷 연결이 필요합니다. 네이버 설정에 `http://127.0.0.1`을 등록하세요. 직접 추출을 사용할 수 없는 경우에는 수집기 안내에 따라 현재 수집기 탭을 공유하세요. 저장된 ZIP으로 분석하는 경우에는 네이버 키가 필요 없습니다.

수집 중 저장 연결이 끊기면 같은 폴더의 **색채연구.exe**를 다시 열고 브라우저에서 **저장 프로그램 다시 연결 → 수집 이어가기**를 누르세요. 저장된 사진을 기준으로 다음 지점이 정해집니다. 새 버전을 다른 폴더에 풀면 별도의 작업 공간이 열립니다. 기존 기록을 이어 쓰려면 기존 폴더의 `runs`와 `captures`를 함께 복사하세요. 이전 분석 결과도 쓰려면 `analysis_jobs` 폴더를 함께 복사한 뒤 **기존 자료 열기 → 이전 분석 결과**에서 여세요.

실행 환경 안내: `runtime`에 Python 3.12.10과 CPU용 PyTorch 2.15.0, torchvision 0.29.2가 포함됩니다. Python 사용권은 `runtime/LICENSE.txt`, Python 패키지의 사용권은 `runtime/Lib/site-packages` 각 배포 패키지에서 확인할 수 있습니다.

화면을 받지 못해 누락된 이전 수집 기록은 **기존 자료 열기 → 수집 이어가기**에서 열고, 지도에 연결한 뒤 **누락된 지점 다시 수집**을 누르세요. 이미 저장된 사진과 중복으로 기록된 지점은 유지됩니다.

새 수집을 시작할 때마다 실행 폴더의 `captures\YYYY-MM-DD_HHMMSS`에 사진과 촬영 기록을 함께 저장합니다. 같은 수집을 이어가면 그 폴더를 다시 사용하고, 같은 초에 시작한 별도 수집은 번호를 붙여 구분합니다. 기존 도로명 폴더의 사진도 원래 위치에서 열 수 있습니다. 수집 기록은 `runs`, 분석 결과는 `analysis_jobs`에 수집별로 연결되며 재분석도 별도 작업으로 저장됩니다. 색 분석에는 수집 메타데이터가 지정한 장면 범위의 픽셀을 사용합니다. 탭 캡처의 경우 장면 안에 거리뷰 화면 표시가 남을 수 있으므로 분할 결과와 함께 검토하세요. 클립 파일은 용량이 클 수 있습니다.

면적 비율은 분석에 포함된 사진의 전체 픽셀을 분모로 계산합니다. 사진마다 색상 비율을 단순 평균하지 않고 실제 픽셀 수를 합칩니다. 색은 정렬된 원본 장면의 sRGB에서 읽고, 밝기는 L*, 채도는 HSV의 S로 계산합니다. 요소별 트리맵에는 미분류 픽셀도 포함됩니다. 도로 통합 팔레트에서 분류된 14개 요소나 개별 요소만 골라 볼 수도 있습니다. 연구용 11개 그룹에서 모델이 지원하지 않는 차량·사람·광고는 JSON에 미지원으로 표시합니다. 연구 그룹에 묶이지 않는 클래스도 원본 ID와 함께 보관합니다.

baseline 모델의 전달 기록상 검증 mIoU는 13.57%입니다. 이 버전의 자동 분할은 초안 검토용입니다.
